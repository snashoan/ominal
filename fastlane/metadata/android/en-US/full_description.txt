Built for people who want coding agents without living in a terminal all day. Conversations stay up front, and each one has its own shell, files, and display when work needs to happen.

Pick a supported agent harness, sign in through its normal flow, attach files, and move between the conversation and workspace without leaving the app. The first launch prepares the Linux environment. After that, agent context, files, and terminal activity stay with the conversation.

This is an experimental developer build, not a hosted AI service. It does not provide models or run a model backend. The selected harness talks to its provider under that provider's terms.

Agent tools can run commands and change files in the app workspace. Check important actions and outputs before relying on them.
