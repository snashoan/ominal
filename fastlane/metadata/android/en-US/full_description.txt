Ominal is a mobile workspace for coding agents. Conversations remain the primary interface, with each workspace connected to an isolated local shell and display session when work needs to run.

Set up an account, start a conversation, attach files, and move between the chat and the active workspace without leaving the app. Ominal prepares its local runtime during first launch, then keeps each workspace's agent context, files, and terminal activity together.

The runtime is designed for current Android devices and does not require device rooting. It can install development tools inside its app-managed Linux environment while keeping the Android app and its data isolated from other apps.
