# GIR quick start

GIR is conversation-first. Describe the outcome instead of opening setup menus.

Example requests:

- `Inspect this project, run its tests, and fix the failing path.`
- `Open the screen when you need me to finish the sign-in.`
- `Install the browser and verify this page at phone size.`
- `Create a theme named custom-x with a quiet monochrome interface.`
- `Attach this file to the current workspace and summarize it.`
- `Use the current conversation with another installed intelligence harness.`

Each chat owns its workspace and persistent harness session. The shared Linux
screen stays available to both GIR and the user, and GIR requests manual input
only when a task requires it.
