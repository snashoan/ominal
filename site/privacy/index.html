Privacy policy

Effective August 2, 2026

Monolith (com.ominal) is a local-first Android application maintained by snashoan. It provides a conversation interface for user-selected coding-agent harnesses and a Linux workspace that runs on the user's device.

Data stored on the device

Monolith may store conversations, execution receipts, workspace files, Linux runtime files, interface preferences, and authentication material created through a selected harness's own sign-in flow inside Android app-private storage. Android backup is disabled for this data.

Connected agent providers

Monolith does not operate an account system or model backend. A selected harness communicates directly with its provider. Prompts, conversation context, command output, and files the user asks the agent to inspect may be transmitted to that provider to produce a response. The provider's privacy policy and account terms govern its processing.

Monolith does not collect provider passwords. Authentication occurs through the provider's browser or command-line sign-in flow, and resulting credentials remain in the app-private Linux environment unless exported by the user or provider software.

Network and websites

The app and local Linux environment may access the internet for the selected agent provider, user-selected tool and package updates, and websites opened by the user or agent. External services handle data under their own policies.

Permissions

The Google Play build uses network access, network-state access, notifications, wake lock, vibration, and a foreground service for visible, user-started agent and shell sessions. It does not request all-files access, package-installation access, display-over-other-apps access, location, contacts, microphone, camera, or advertising identifiers.

Files are imported and exported through Android's system document interfaces, where the user chooses the file or destination.

Analytics and advertising

Monolith contains no advertising SDK, analytics SDK, or automatic developer telemetry. It does not automatically upload logs or conversations to a server operated by snashoan.

Retention and deletion

Monolith does not create a Monolith account. Clearing app storage or uninstalling removes app-private data. Files exported to shared storage must be removed separately. Deleting local data does not delete information already processed by an external provider; provider deletion requests must be made through that provider.

Security

Monolith relies on Android application isolation and app-private storage. Agent harnesses can execute commands and access workspace files, so users should review sensitive or irreversible actions and only provide data they are comfortable sharing with the selected provider.

Children

Monolith is a developer tool and is not directed to children under 13.

Changes

This policy may be updated when the application's data handling changes. The effective date identifies the current version.
